# 📚 Smart Timetable Scheduler

An intelligent, web-based timetable generator built with **Python**, **Streamlit**, and **Pandas**. Designed to automate university scheduling by handling constraint validation, consecutive lab allocations, and multi-format exports.

---

## ✨ Features

- ⚡ **Dynamic Inputs:** Configure working days, hours per day, subjects, and faculty assignments.
- 🔬 **Smart Lab Allocation:** Automatically schedules 2 consecutive time slots for lab modules.
- 🚫 **Conflict Detection:** Identifies overbooked hours and faculty availability constraints.
- 📥 **Multi-Format Exports:** Export finalized schedules to formatted **Excel (.xlsx)** and **PDF (.pdf)** files.
- 📊 **Real-time Analytics:** Visualizes slot utilization, weekly totals, and free periods.

---

## 🛠️ Tech Stack

- **Frontend / Dashboard:** Streamlit
- **Data Processing:** Pandas
- **Export Engines:** OpenPyXL (Excel), FPDF2 (PDF)
